# 🔎 Lost & Found

A simple web platform for reporting, discovering, and recovering lost or found items.

The project is being developed as a **2-person React project**, starting with a small UI-focused MVP and planned to scale with backend, database, and additional features in future versions.

## 🚀 Current Goal

The initial version focuses on creating a clean and responsive interface where users can:

* Browse lost items
* Browse found items
* View item details
* Report a lost item
* Report a found item
* Upload item images and information
* Provide contact details
* Mark an item as returned
